## 🔧 KEY TECHNICAL DETAILS

### Technology Stack:
- **Backend**: Spring Boot 3.5.14, Java 17
- **Database**: MySQL 8
- **Security**: JWT (stateless), BCrypt
- **ORM**: Hibernate 6.6, Spring Data JPA
- **API Docs**: Swagger/OpenAPI 3
- **Build**: Maven (wrapper included)

### Architecture:
- **Layered**: Controller → Service → Repository → Entity
- **Security**: JWT filter chain, role-based @PreAuthorize
- **Validation**: Field-level + business logic
- **Exception Handling**: Global handler with proper responses
- **DTOs**: Request/Response separation
- **Database**: Triggers + procedures at DBMS level
